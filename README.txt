PIXELFORGE PHOTO EDITOR — LOCAL SERVER

1. Install Python 3 if it is not already installed.
2. Double-click start.bat.
3. Open http://127.0.0.1:8000 in your browser.
4. Upload an image. It will load into the editor and be copied to data/inputs.
5. Click Export image. It will download to your browser and be saved to data/outputs.

Folders:
  data/inputs  = original images you uploaded
  data/outputs = exported images

No pip packages or internet connection required. The server listens only on your own PC (127.0.0.1).
Maximum upload size: 100 MB per image.
